# Site Copy

## Page title

GitHub Actions Log Copy

## Hero title

Copy GitHub Actions step logs with one click.

## Hero body

GitHub Actions Log Copy adds a copy button directly to each step header on GitHub Actions job pages, so you can grab exactly the output you need without scrolling and drag-selecting giant logs.

## Features section title

Built for the one annoying thing GitHub Actions still makes hard.

## Features bullets

- Copy a single step's logs directly from the step header
- Auto-expand collapsed steps before copying
- Copy only the log lines for the selected step
- Work reliably with long GitHub Actions logs

## How it works section

GitHub virtualizes long logs in the page, which makes normal text selection frustrating and sometimes incomplete. GitHub Actions Log Copy adds a focused copy control for each step and pulls the full step log when GitHub makes it available.

## Trust section

Open source, MIT licensed, and intentionally minimal.

- No analytics
- No third-party servers
- No user data storage
- Only runs on GitHub Actions job pages
